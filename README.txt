AGdevlopers Real Estate Client Demo
====================================

Concept brand: NESTORA Realty
Target: mainstream/local real estate agents, property consultants, builders and brokers.
This is intentionally NOT a luxury-only property site. The design focuses on trust, clarity, practical search and lead generation.

Research-informed features:
- Buy / Rent / Sell modes
- Search by locality
- Property type and budget filters
- Featured property cards with practical details
- Verified / featured badges
- Locality guidance
- Buy, rent, sell and investment services
- Simple 4-step process
- Strong WhatsApp / call / email conversion
- Responsive mobile navigation
- Floating WhatsApp CTA

The reference research found that Indian property users commonly need location search, filters, property details, verified listings, locality insights and direct contact. The demo therefore prioritizes those functions over a luxury aesthetic.
